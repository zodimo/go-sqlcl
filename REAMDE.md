# GO SQLCL 

- language: go 1.24
- package name: github.com/zodimo/go-sqlcl

The sqlcl applciation from oracle is an commandline application of oracle sqldeveloper. The application mainly runs a repl(Read-Eval-Print Loop) in the terminal which makes is hard to use from a "scripting" perspective.
This package aims to provide a scriptable api provide 100% feature coverage of the sqllcl application while using the sqlcl repl under the hood.
